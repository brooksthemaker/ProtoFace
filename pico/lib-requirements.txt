# CircuitPython libraries needed on the Pico (copy into CIRCUITPY/lib/).
#
# Built into the CircuitPython firmware (no copy needed) on RP2350 builds:
#   rgbmatrix, framebufferio, displayio, bitmaptools, gifio, ulab, audiobusio,
#   busio, board, supervisor, keypad
#
# From the Adafruit CircuitPython Library Bundle (match your CP major version,
# e.g. bundle 9.x for CircuitPython 9.x) — download from
# https://circuitpython.org/libraries and copy these into CIRCUITPY/lib/:
#
#   adafruit_imageload/         # load baked BMP face assets        (Phase 1, required)
#   adafruit_mpu6050.mpy        # gyro / accelerometer input        (Phase 4, optional)
#   adafruit_bus_device/        # dependency of adafruit_mpu6050    (Phase 4, optional)
#   adafruit_register/          # dependency of adafruit_mpu6050    (Phase 4, optional)
#
# Verify rgbmatrix/gifio/ulab exist on your board:
#   import rgbmatrix, gifio; from ulab import numpy   # at the REPL
# If gifio/ulab are missing, flash a full CircuitPython build for your board.
